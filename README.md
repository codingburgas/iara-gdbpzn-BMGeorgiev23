# ГДПБЗН - Система за управление на произшествия

![ГДПБЗН Logo](app/static/images/logo.png)

## Система за управление на произшествия и пожарни екипи

Главна дирекция "Пожарна безопасност и защита на населението" (ГДПБЗН) е част от Министерството на вътрешните работи на Република България. Тази система е предназначена да подпомогне основните оперативни дейности в ежедневната работа на пожарникарите, включително управление на произшествия, координация на екипи, комуникация и ресурси.

## Функционалности

### Потребителски роли

| Роля | Описание |
|------|----------|
| **Администратор** | Пълен достъп до системата, управление на потребители, роли и станции |
| **Мениджър произшествия** | Управление на произшествия, разрешаване, маркиране на фалшиви сигнали |
| **Диспечер** | Създаване на произшествия, назначаване на екипи, комуникация |
| **Пожарникар** | Оперативен персонал, достъп до табло, произшествия, екипи, комуникации, ресурси |
| **Потребител** | Докладване на произшествия, преглед на своите доклади |

### Основни модули

| Модул | Описание |
|-------|----------|
| **Табло** | Общ преглед на активни произшествия, налични екипи, успеваемост и спасени животи |
| **Произшествия** | Създаване, преглед, редактиране, разрешаване и изтриване на произшествия |
| **Екипи** | Управление на пожарни екипи, назначаване на членове, автоматичен статус |
| **Операции** | Интерактивна карта с произшествия и екипи, назначаване на екипи от картата |
| **Комуникации** | Чат канали, видео обаждания, известия, спешни съобщения |
| **Ресурси** | Управление на ресурси в станциите, преместване и премахване |
| **Доклади** | Анализи, статистики, ефективност на екипите |
| **Потребители** | Управление на потребители, роли, станции (само за администратори) |
| **Профил** | Лична информация, смяна на парола, профилна снимка |

### Ключови функции

- **Автоматичен статус на екипите** - Определя се на база активни произшествия
- **Карта с местоположение** - Интерактивна карта с маркери за произшествия и екипи
- **Станции** - 3 станции в София (Център, Люлин, Младост)
- **Препоръчани екипи** - При произшествие се показват екипи от най-близката станция
- **Фалшиви сигнали** - Маркиране и автоматично предупреждение за потребителя
- **Прикачени файлове** - Качване на снимки и документи към произшествия
- **Тъмна тема** - Поддръжка на светла и тъмна тема

## Инсталация

### Изисквания

- Python 3.10 или по-нова версия
- pip (Python package manager)
- Git

### Стъпки за инсталация

#### 1. Клониране на репозиторито

```bash
git clone https://github.com/your-username/gdpozharna-system.git
cd gdpozharna-system
```

#### 2. Създаване на виртуална среда

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate
```

#### 3. Инсталиране на зависимости

```bash
pip install -r requirements.txt
```

#### 4. Конфигурация на средата

Създайте `.env` файл в основната директория:

```env
FLASK_APP=run.py
FLASK_ENV=development
SECRET_KEY=your-super-secret-key-here
DATABASE_URL=sqlite:///instance/gdpozharna.db
```

#### 5. Инициализиране на база данни

```bash
# Създайте instance папката
mkdir instance

# Стартирайте приложението (създава базата автоматично)
python run.py
```

#### 6. Създаване на администратор

При първо стартиране се създава автоматично администраторски потребител:

| Имейл | Парола |
|-------|--------|
| admin@example.com | admin123 |

#### 7. Стартиране на приложението

```bash
python run.py
```

Приложението ще бъде достъпно на: `http://localhost:5000`

## Стартиране

### Разработка

```bash
# Активиране на виртуалната среда
venv\Scripts\activate  # Windows
source venv/bin/activate  # macOS / Linux

# Стартиране
python run.py
```

### Продукция (с Gunicorn)

```bash
# Инсталиране на Gunicorn
pip install gunicorn

# Стартиране
gunicorn -w 4 -b 0.0.0.0:8000 "app:create_app()"
```

### Docker

```bash
# Изграждане на Docker образ
docker build -t gdpozharna .

# Стартиране на контейнер
docker run -p 5000:5000 gdpozharna
```
